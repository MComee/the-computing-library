# Computer Science Mastery Library

> **261 bibliographic entries.** All 190 original entries retained; additions cover canonical hacker/computing literature, Rainbow Series documents, and previously underrepresented fields.

## How to use this repository

- Read by topic, not by year. These are reference and exploration paths, not a required sequential curriculum.
- Every book has a stable `B###` ID; a work can appear in several conceptual indexes without creating a new bibliographic entry.
- **Canonical / cultural nickname** indicates a widely used informal name, not a formal bibliographic title.
- **Historical / superseded** material is useful for foundations and culture, not necessarily current implementation or security practice.
- Detailed coverage is a **topic-based guide**, not a verified chapter-by-chapter table of contents. Editions differ.
- Resource links point to course or official educational resource pages; free access and site availability can change.

## Sources and inclusion policy

- Baseline: the original 190-entry list in this conversation, preserved as written.
- Source documents: *Seven Checks Protocol Version 2* and *Master Development Plan: Computer Science, Information Theory, and Psychology* (five-year framing removed; topical structure retained).
- The Master Plan also references W3C RDF and OWL 2 specifications, included as free technical references rather than misclassified as books.
- The Seven Checks Protocol references freeCodeCamp and two GitHub projects, included as web resources below.
- Rainbow Series entries are an **expanded selected index**, not a certified complete inventory of every color-coded NCSC publication; historical titles and document numbers require edition-level catalog verification.
- Retained historical/duplicate-like entries may represent the same work or a component of a work. No original entries were deleted.
